# Font Licenses

V1G2 Simple embeds two open-source fonts in firmware flash and uses them in the web UI.

---

## Barlow Condensed Bold (firmware + web UI)

Used as the primary alert display font for the **V1G2 Simple** display style (band names, frequencies, speed, threat count). Chosen for its DIN 1451 engineering-condensed proportions and avionics readability.

- **Font:** Barlow Condensed Bold  
- **Author:** Jeremy Tribby  
- **License:** SIL Open Font License 1.1  
- **Source:** https://github.com/jptribby/barlow  

---

## Inter Medium (firmware + web UI)

Used as the secondary/UI font for the **V1G2 Simple** display style (settings, menus, status labels) and as the web UI body font.

- **Font:** Inter  
- **Author:** Rasmus Andersson  
- **License:** SIL Open Font License 1.1  
- **Source:** https://github.com/rsms/inter  

---

## SIL Open Font License 1.1

Both fonts are licensed under the [SIL Open Font License 1.1](https://scripts.sil.org/OFL), which permits:

- Free use in commercial and non-commercial products
- Embedding in firmware and software distributions
- Modification and redistribution (under the same license, not standalone font sales)

The fonts are subsetted to the glyphs actually used by the display (digits 0–9, decimal point, and specific ASCII characters for band names and labels) to minimise flash usage.
